# Pełną Piersią - Portal Blogowy

Nowoczesny portal blogowy stworzony w technologii Java (Spring Boot) z estetycznym i responsywnym frontendem.

## Funkcje
- **Panel Administratora**: Pełne zarządzanie postami (CRUD).
- **Bezpieczeństwo**: System logowania (Spring Security).
- **Magiczne Formatowanie AI**: Inteligentne formatowanie tekstu w edytorze Quill.js.
- **Interakcje**: Komentarze, reakcje (Lajki, Serca, Smutne minki) oraz licznik wyświetleń (IP tracking).
- **Responsywność**: Strona w pełni dostosowana do urządzeń mobilnych.
- **Statystyki**: Zaawansowany panel analityczny dla administratora.

## Technologie
- **Backend**: Java 17, Spring Boot 3.2.5, Spring Data JPA, Spring Security.
- **Baza danych**: H2 (trwała, zapisywana w pliku `blogdb_v2`).
- **Frontend**: HTML5, CSS3 (RWD, Flexbox, Grid), JavaScript, Thymeleaf.
- **Edytor**: Quill.js.

## Uruchomienie
1. Sklonuj repozytorium.
2. Uruchom aplikację za pomocą Maven: `mvn spring-boot:run` lub przez IDE (np. IntelliJ).
3. Aplikacja będzie dostępna pod adresem: `http://localhost:8080`.
